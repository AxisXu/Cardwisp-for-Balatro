# 开包、出牌与盲注的只读决策核对

本机 Codex CLI 桥接在玩家提问时锁定最新公开局面，再按阶段提供可核对的依据。仍只给建议，不点击卡牌，也不执行出牌。商店的费用和利息核对见[商店决策流程](shop-decision-flow.md)。

| 场景 | 提问前核对 | 明确保留的未知 |
| --- | --- | --- |
| 开包 | 卡包类别、剩余选择次数、已经出现的选项、效果解析状态、小丑或道具槽位，以及比赛信息 | 背面选项、未打开卡包内容；候选牌仍在生成时不请求模型 |
| 出牌 | 盲注目标、已得分与差额、剩余出牌/弃牌次数、明牌及选中状态、当前牌型预览与各牌型等级 | 背面手牌、抽牌顺序、受所有小丑与触发顺序影响的最终得分；当前预览不冒充完整算分 |
| 选盲注 | 当前可见的盲注目标、奖励、效果、跳过标签、可用的 Boss 重掷，以及牌组与比赛信息 | 尚未显示的 Boss 盲注、未来标签、精确获胜概率 |

比赛信息的牌型等级/使用次数、已购优惠券与本底注已显示的盲注现在在商店、开包、出牌、选盲注阶段都传给模型；隐藏盲注仍不传。游戏进入开包阶段后，候选牌可能稍晚才进入游戏卡牌区域。牌灵会在候选牌出现或变化时立即发布新局面；如果模型回答期间选项、手牌或盲注已变化，则丢弃旧回答。尚未出现任何开包选项时直接提示稍后重试，避免按空列表给建议。

卡牌说明中的动态数字来自游戏能力字段，而本地化文本使用占位符。牌灵只对已核对的原版变量进行替换：例如「杂耍师」的手牌上限、「偶数史蒂文」的倍率，以及常见直接读取 `extra` 的小丑。原始数值也保留在 `visible_values` 中。尚未映射的占位符继续标为未知，不会用某个能力值猜填；这是后续卡牌效果覆盖率审计的重点。

自动测试验证依据构造、旧局面丢弃、开包候选牌出现后的立即发布签名及比赛信息的跨阶段可见性。真实游戏中的建议质量、触发时序和界面体验仍需实机验收。当前直连兼容模型服务路径尚未接入这一核对层。
